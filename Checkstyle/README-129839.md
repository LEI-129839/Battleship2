## O que o Checkstyle não consegue verificar
O Checkstyle só compara a forma do nome com uma expressão regular, por isso aceita constantes como `X`, `VALOR_1` ou `COISA` que não dizem nada sobre o que representam. Também não verifica se o nome é significativo, se está escrito de forma consistente em português ou inglês, nem se um campo `static final` mutável (por exemplo uma lista) devia sequer ser tratado como constante.
